# Timbre — landing page

Site estático em português, criado a partir dos canais públicos da Timbre Comunicação e Marketing Digital. Os arquivos para edição estão em `dist/`: `index.html`, `style.css`, `script.js` e `assets/`.

Abra `dist/index.html` em um navegador para visualizar. Não exige instalação, banco de dados ou uma etapa de compilação. Para editar com Claude, envie os três arquivos principais e os materiais visuais. Para publicar em outra hospedagem estática, envie o conteúdo de `dist/`.

As fotos e a marca foram recuperadas dos canais públicos da empresa. Os arquivos originais e sua procedência estão documentados em `asset-sources.json`. As imagens pertencem aos respectivos titulares; publicação pública não equivale a licença irrestrita de reutilização.

O Instagram não permitiu leitura direta completa. A identidade foi conferida no logo oficial, nas imagens publicadas no LinkedIn da empresa e na configuração de seu Linktree. A página usa a paleta confirmada, com rosa mais escuro em textos e botões para legibilidade. A palavra Timbre usa uma aproximação tipográfica em Georgia; o símbolo é o arquivo original da marca. O cartão Filó é uma composição editorial criada para a página, não uma captura do site ou reprodução da marca da cliente.

Os textos são uma proposta de redação para a landing page; as etapas de trabalho são uma estrutura sugerida para revisão pela empresa. Não foram inventados números de resultados, depoimentos nem clientes. Os botões de contato abrem o WhatsApp e o aplicativo de e-mail; não há formulário, coleta ou envio automático de dados.

## Interações

Entradas progressivas na rolagem, símbolo flutuante, faixa animada, indicadores rítmicos, cartões com movimento ao passar o mouse, menu móvel, detalhes expansíveis de serviços, progresso de leitura e opção de pausar animações. A preferência do sistema por movimento reduzido é respeitada.

O manifesto `.openai/hosting.json` identifica esta versão hospedada e não é necessário para abrir os arquivos localmente. A página foi disponibilizada com acesso privado para revisão.
